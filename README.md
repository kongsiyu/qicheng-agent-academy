# 启程 · Agent Academy

面向非技术岗位的 AI Agent 学习 Web 工具。课程与交互完全在浏览器执行；服务端仅需托管静态文件，无需数据库、账户服务或模型调用服务。

## 开始使用

仓库根目录就是可直接部署的网站目录。推送到 GitHub 后，可以在仓库 Settings → Pages 中选择 `Deploy from a branch`、`main` 分支和 `/ (root)` 目录启用 GitHub Pages。

Windows 下双击同目录的 `开始使用.cmd`，或在本目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 `http://localhost:8765`。建议固定使用同一个地址和端口，浏览器会按站点地址分别保存记录。

也可以将本目录的全部文件放到任意静态文件托管服务。入口是 `index.html`，页面使用 hash 路由，无需配置服务端页面重写。发布到 HTTPS 后支持离线缓存和添加到主屏幕。

直接打开 HTML 也能浏览，但浏览器对 `file:` 地址的本地存储支持不同，建议通过上面的本地静态服务或正式静态站点使用。

## 已实现的学习闭环

- **学习总览**：当前目标、下一课、课程与独立成果两条进度、能力积累。
- **学习路线**：4 周主线 12 节课程，加 2 周选修 3 节课程；共 15 节短课，均有测验与反馈。
- **任务实验室**：会议待办、竞品简报、表格分析、产品资料问答、文稿初审、项目周报 6 个完整任务包。
- **边做边学**：示例资料、任务说明复制、四步引导、参考成果、验收清单、常见问题与进阶挑战。
- **独立练习**：在自己常用的 Agent 中执行，把结果带回验收；支持 TXT、MD、CSV 资料导入、草稿自动保存。
- **我的成果**：保存资料、实际输出和复盘；可导出单份 Markdown 作品。
- **目标与记录**：3 种目标、岗位方向、每周投入，完整 JSON 备份导出与严格校验后恢复。
- **离线使用**：首次通过 HTTPS 或 localhost 加载并完成缓存后，课程与本地练习可离线打开；外部 Agent 的运行依赖其自身网络。

## 进度规则

课程只有答对测验才记录为已掌握。重复通过不会重复计数。

独立成果需要选择“独立练习”、填写自己的资料和实际输出，并确认全部验收项。“看过示例”不增加独立成果数量。修改资料或结果会清除验收状态，需要重新验收。

总目标进度为“目标课程完成比例”和“独立成果完成比例”的平均值，两者分别封顶 100%。starter 和 efficient 目标仅计 12 节主线课程；builder 目标计全部 15 节。选修课程不会影响前两个目标的分母。调整目标会保留既有记录。

验收表是用户自检记录，当前版本不做模型评分。示例成果是预置教学内容，不会伪装成实时模型输出。

## 客户端架构

| 文件 | 用途 |
| --- | --- |
| `index.html` | 应用入口与固定页面框架 |
| `content.js` | 课程、测验、任务包和目标静态数据 |
| `core.js` | 状态规范化、导入校验与进度计算；同时支持 Node 验证 |
| `app.js` | 路由、渲染、学习交互、本地存储与文件导入导出 |
| `styles.css` / `details.css` | 桌面与手机布局、组件样式 |
| `sw.js` | 同源静态文件离线缓存 |
| `manifest.webmanifest` | Web 应用安装信息 |

没有运行时第三方依赖、远程字体、分析脚本或图片 CDN。无需 npm 安装或构建步骤。用户文本以转义后的文本形式呈现。

学习记录保存于当前站点浏览器的 localStorage，键名为 `qicheng.agent-academy.v1`。课程数据与学习记录分开，进度由已完成事实计算。自动保存失败时会提示导出备份。不同设备或浏览器之间需要用 JSON 备份迁移，当前没有云同步。

## 内容维护与后续扩展

编辑 `content.js` 即可维护课程和任务。保留已发布内容的稳定 ID；字段结构见现有条目。新增主线内容时需同时维护目标中的 `targetLessons`。升级已发布数据结构时，应增加 schema 迁移逻辑。

第一版保留“复制任务说明 → 在常用 Agent 中执行 → 带回验收”的使用方式，以控制服务端和模型成本。后续如加入模型陪练，可独立添加可选接口层，并明确处理授权和密钥；现有课程、目标和进度不依赖它。

## 验证记录

已验证核心进度算法、示例与独立任务区分、选修目标范围、严格备份恢复、异常和超长内容拒绝；浏览器中验证了测验、刷新恢复草稿、独立成果验收、目标切换、备份下载与恢复、损坏备份保留原记录，以及手机与桌面布局。停止本地服务器后刷新页面，已缓存的课程与界面仍可打开。

如已安装 Node.js，可在本目录运行 `node tests/core.test.cjs` 复查核心数据与进度逻辑。
