# 启程 · Agent Academy

面向非技术岗位的 AI Agent 学习 Web 工具。课程、进度和离线练习在浏览器运行。AI 教练课由学员在浏览器连接自己的模型服务。

版本说明（2026 年 11 月 21 日）：在统一逐步练习与 C · 深靛灰主题基础上，新增六门按需选学的场景课程及配套任务。

主题已按选定的 **C · 深靛灰** 实装：画布 `#171b24`、侧栏 `#131720`、卡片 `#222836`、输入区 `#1a202c`、正文 `#e3e8f0`、强调色 `#b0bdf0`。三份样式表共用语义颜色变量，强调色用于主要操作、当前步骤和选中位置；正文、辅助文字、提示、错误反馈及弹窗均采用深色主题。浏览器原生控件启用 dark color-scheme；打印时回到浅色纸面。

## 开始使用

仓库根目录就是可直接部署的网站目录。推送到 GitHub 后，可以在仓库 Settings → Pages 中选择 `Deploy from a branch`、`main` 分支和 `/ (root)` 目录启用 GitHub Pages。

Windows 下双击同目录的 `开始使用.cmd`，或在本目录运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 `http://localhost:8765`。建议固定使用同一个地址和端口，浏览器会按站点地址分别保存记录。

也可以将本目录的全部文件放到任意静态文件托管服务。入口是 `index.html`，页面使用 hash 路由，无需配置服务端页面重写。发布到 HTTPS 后支持离线缓存和添加到主屏幕。

直接打开 HTML 也能浏览，但浏览器对 `file:` 地址的本地存储支持不同，建议通过上面的本地静态服务或正式静态站点使用。

### 配置 AI 教练模型

从学习设置或教练课打开「配置模型」，填写 OpenAI 兼容接口地址、模型名和服务要求的 API 密钥，点「测试连接」后保存。浏览器会直接调用所填接口，网站由静态托管提供。HTTPS 接口需支持当前页面来源的跨域请求，模型需支持课程使用的结构化 JSON 回复。

使用本机 Ollama 时，可设置 `OLLAMA_ORIGINS` 为托管课程的页面来源。例如课程在 `http://127.0.0.1:8764` 时，可先运行以下命令启动 Ollama。

```sh
OLLAMA_ORIGINS=http://127.0.0.1:8764 ollama serve
```

在另一个终端运行 `ollama pull qwen2.5:7b`。配置填写 `http://127.0.0.1:11434/v1` 和 `qwen2.5:7b`，密钥留空。使用云模型时，请填写服务提供的 HTTPS API 地址和个人密钥。连接信息保存在当前浏览器，密钥默认只在当前标签页会话保留。「在此浏览器记住密钥」可将密钥保存在当前浏览器。学习备份只包含学习记录，模型配置另存。

## 已实现的学习闭环

- **学习总览**：一个明显的开始入口，首次推荐约 15 分钟的会议待办练习；课程路线与成果记录作为后续入口。
- **默认三步练习**：准备资料 → 让 Agent 帮忙 → 检查并保存。按步骤依次呈现，默认主要文本输入数为 **0 / 1 / 0**。
- **资料与说明已备好**：可直接用示例，按需换成自己的资料。复制时自动合并本次资料与任务要求，无需重复粘贴或先编写完整说明。
- **轻量保存**：唯一需要手动填写的主要文本是 Agent 的实际输出；自检未全部勾选也可保存，问题或修改只需一句且选填。更换自己的资料时仍需提供可处理的内容。
- **学习路线**：4 周主线 14 节、2 周进阶选修 3 节，加 6 门按需场景课，共 23 节。场景课不增加原有 14/17 节学习目标的分母，也不占用第 7 周。
- **任务实验室**：原有会议待办、竞品简报、表格分析、产品问答、文稿初审和周报，加 PDF 阅读、邮件、客户反馈、汇报、Excel 清理和文件命名，共 12 个任务；分两组展示，点击即进入同一三步流程。
- **工作流实验**：客户反馈练习先分类、去重，再结合客服回访分流。周会待办练习让 Agent 提取事项，学员结合会后消息审核，再把决定发回同一个 Agent 对话，带回它写的交接消息。共用的工作流界面负责传递已确认产物、记录审核决定和保存成果，各案例可以独立续做。
- **场景课练习材料**：每门含方法、带理由示范、三类辨错反馈、正常/资料不足/冲突/独立/迁移/延后等不同材料；PDF、Excel 和文件命名另提供可选下载文件。默认只需粘贴实际输出，不额外要求打分或复盘。
- **进阶项目**：独立入口保留带理由的示范、辨错、减少提示、个人任务包、正式独立任务、迁移、完整时间账及选修实测。首次练习不要求前测、人工基线、八项自评或耗时填写。
- **正式比较与抽评**：需要研究学习效果时，由主持人主动安排学前 Agent 尝试、等难后测和延后复验。人工原流程耗时基线另行记录；自评与材料可导出供人工抽评。
- **我的成果**：优先展示新练习记录；旧自检成果在可展开历史区保留，资料、输出与导出仍可用。
- **目标与记录**：3 种目标、岗位方向、每周投入，完整 JSON 备份导出与严格校验后恢复。
- **离线使用**：首次通过 HTTPS 或 localhost 加载并完成缓存后，课程与本地练习可离线打开；外部 Agent 的运行依赖其自身网络。

## 进度规则

课程答对测验只记录为“理解检查通过”。重复通过不会重复计数，不据此认定能力掌握。

2026 年 11 月 20 日重构后的普通练习使用 `kind: practice`，只允许 `support: guided`。保存时检查有效资料、自动提供的任务说明和实际输出；不要求核查长文、纠错长文、权限判断、八项评分、耗时或全部自检勾选。默认示例和说明已经满足前两项，手动必填仅为实际输出（至少 20 个字符）。这是真正分开的校验分支，不是把正式必填表单藏进折叠区。

`practice` 可以显示在保存记录中，但不计正式周项目、八项能力等级或延后复验；勾完普通练习自检也不会自动升级为独立完成。未确认的检查项按原状保留。

原有单次练习继续保留为“普通自检成果”，不自动转成项目证据。正式验收的默认核查文本合并为一条 `sourceCheck`：关键结论＋资料依据＋实际核查结果；`correction` 为发现问题后的选填修改记录，不要求编造错误。`decision` 仅在 `missing`、`conflict` 或 `automation-*` 类型必填，其余类型有需要时记录。前测和人工基线仍按各自规则保存；四项正式自检、迁移调整、选修实测、真实工作日期与完整时间账门槛继续保留。

修改关键内容会清除草稿验收勾选；存档快照不随草稿改变。发现存档有误可撤回自评，保留原文并从项目与能力进度排除。

学习计划进度为目标课程理解检查比例与每周项目证据齐备比例的平均值。starter 和 efficient 计 14 节主线课程与前四周项目；builder 计全部 17 节及六周项目。选修不影响四周目标分母。

第 1 周选题并完成正常案例；第 2 周主线正常/缺失/冲突三组案例；第 3 周形成六项任务包及他人使用反馈；第 4 周独立交付、第二任务迁移、完整真实工作时间账，以及至少两个实际工作日期覆盖七个日历日。教学案例不能满足真实使用跨度；覆盖一周不等于每日连续使用。结课独立记录七天后另做延后复验，不提前判完成。选修要求外部助手实测，以及自动化正常/缺字段/重复输入的实际运行记录。

验收表与能力等级均为学员自评。系统检查记录是否完整，不判断事实正确或替代教师抽评。选择“独立”不会自动改变提示情况；使用过课程或他人提示应如实记录。助手和自动化在外部获准使用的工具执行，站内填写不表示已创建助手或接通系统。示例为预置教学材料。

课程的质量设计、评分锚例与真实试学方案见 [课程质量设计](docs/course-quality-design.md) 和 [试学指南](docs/pilot-guide.md)。尚未开展真实用户试学，不提供虚构的学习成效数据。

学习记录保存于当前站点浏览器的 localStorage，键名继续使用 `qicheng.agent-academy.v1`，数据结构升级为 schemaVersion 2。旧版记录和备份经严格校验后迁移，原课程与普通自检成果保留，新项目证据为空。新版备份包含项目草稿、快照、撤回、自评和任务包。每份学习证据最多 500 次存档且总量不超过 4 MiB UTF-8；完整备份导入上限 16 MiB。不同设备需用备份迁移，当前没有云同步。

## 内容维护与后续扩展

通过 `content.js`、`curriculum.js` 与 `scenario-courses.js` 维护课程、任务和案例。保留已发布内容的稳定 ID；字段结构见现有条目。新增主线内容时需同时维护目标中的 `targetLessons`；按需场景课追加在进阶选修后，不改变现有目标。修改正式验收时检查 `practice` 的轻量保存仍独立可用；升级已发布数据结构时，应增加 schema 迁移逻辑。

新增场景课的默认输入是文字材料；可选 PDF/XLSX/ZIP 用于实际文件读取或测试目录操作。文件整理默认只做预览，测试包不含脚本。本站不会替学员上传附件、发送邮件或执行磁盘操作。更换资料时任务说明与四项验收使用通用规则，不固定套用示例人物、日期或统计值。

学习路线中的 AI 教练课共 11 门。每门课在站内完成讲解、理解检查、带练、纠错和独立练习。模型根据当前材料和学习目标理解学员的回答。每门课的对话和进度独立保存在当前浏览器，共用一次模型配置。新增课的案例材料在 `tutor-courses-office.js`、`tutor-courses-analysis.js` 和 `tutor-courses-skills.js`。
